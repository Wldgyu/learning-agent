# AI 학습 Agent

정보처리기사 실기를 위한 로컬 학습 앱입니다. 문제 풀이, 채점, 오답 관리, 복습 일정, 회차별 시험과 AI 학습 기능을 제공합니다.

## 실행

Python 3.11 이상이 필요합니다. PowerShell에서 프로젝트 폴더를 열고 실행하세요.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
.\run.ps1
```

브라우저에서 `http://127.0.0.1:8000`을 엽니다. 이미 `.env`가 있다면 `Copy-Item` 단계는 생략하세요.

## API 키

AI 기능을 사용하려면 `.env`의 `LLM_API_KEY=` 뒤에 설정된 AI 서비스에서 발급받은 API 키를 입력하세요. 키는 서버에서만 사용합니다. 키가 없어도 문제 풀이, 채점, 오답노트와 복습 기능은 사용할 수 있습니다.

## 주요 기능

- 오늘의 학습: 풀었던 문제 중 무작위 복습 3~5개와 아직 풀지 않은 기출문제로 최대 20개 구성. 새로고침해도 풀이 기록 유지
- 문제은행: 연도, 회차, 분야 및 문제 내용 검색
- 회차별 시험: 한 회차의 20문항을 풀고 결과 확인
- 오답노트: 오답 기록과 다음 복습 날짜 관리
- 복습 문제: 이전에 풀었던 기출 및 AI 문제 목록에서 다시 풀이
- AI 생성 문제: 생성과 검증을 통과한 문제를 별도 목록에서 풀이
- 이론 노트: 기본 개념과 화면에만 표시되는 일회성 AI 설명

## 로컬 데이터

문제와 학습 기록은 프로젝트 폴더의 `questions.sqlite3`에 저장됩니다. 이 파일과 API 키는 저장소에 포함되지 않습니다. 기존 문제 데이터를 사용하려면 본인의 `questions.sqlite3`를 프로젝트 폴더에 두고 실행하세요. 파일이 없으면 빈 데이터베이스로 시작합니다.

서버는 `127.0.0.1`에서만 실행하며 현재 단일 사용자용입니다. 공개 서버로 운영하려면 인증과 사용자별 데이터 분리가 필요합니다.
